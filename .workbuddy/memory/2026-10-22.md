## SkillForge 融合修改（按 modifySuggestion/modify.md 严格执行）

按 modify.md 方案将 SkillForge（SkillBank + ForgeEngine + SkillMutator）移植进 MiniCode：

- 新增 `src/memory/skill-bank.ts`：SkillBank 核心（JSON 存储、关键字检索、recordEpisode 信用分配、formatPrompt 渲染）
- 新增 `src/memory/skill-evolution.ts`：ForgeEngine 四状态生命周期（trial→active→stable/retired）、fitness 驱动进化、容量上限
- 新增 `src/memory/skill-mutator.ts`：基于 ModelAdapter 的 LLM 变异（mutate + analyzeFailures）
- 修改 `src/memory/types.ts`：新增 Skill/SkillBankData/EvolutionSummary/SkillLifecycle 类型
- 修改 `src/memory/runtime.ts`：集成 skillBank/forgeEngine/skillMutator；promptExtras 传 skillBank 并调用 retrieveSkills；completeTurn 增加信用分配+定期进化；distill 增加失败分析生成新 skill；新增 collectSessionFailures
- 修改 `src/prompt.ts`：MemoryExtras 增加 skillBank；buildSystemPrompt 注入 "# Learned Skills (dynamic)"
- 修改 `src/memory/distiller.ts`：distillSessionEnd 增加 options.skillBank，蒸馏 skills 写入 SkillBank（trial 生命周期）
- 修改 `src/memory/constants.ts`：新增 SKILL_BANK_CONFIG
- 修改 `src/tty-app.ts`：新增 /skillbank 命令（显示 skill 列表与 fitness）
